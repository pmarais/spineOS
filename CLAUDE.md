# CLAUDE.md

This repository is a **spine** (SpineOS). Operating instructions for all agents live in [AGENTS.md](AGENTS.md) — read it now, then boot with:

```bash
python3 spine.py seed
```

Skills are installed: `/seed` (boot), `/case <id>` (work one case), `/sitrep <id>` (report). SPINE.md, as printed by the seed, is the binding rule set for the session: append-only ledgers, gates on irreversible actions, SITREP-only reporting.
