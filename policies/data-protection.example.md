# Policy: data protection

**Owner:** admin · **Applies to:** every member and every agent · **Review:** annually

1. Personal data lives only on the spine and its server. The server is in our chosen jurisdiction.
2. Credentials never enter the repo. They live in environment variables or the system keychain.
3. Every clone sits on an encrypted disk. No clone on a personal or shared device.
4. We collect the minimum. We keep source data verbatim and never edit it (research dogma).
5. A subject-access or deletion request goes to the admin the same day it arrives.
6. A suspected breach is appended to a case ledger immediately and escalated to the admin. We do not
   investigate quietly.
7. Agents follow this policy as members do. An agent never sends personal data to any external
   service that the operator did not name.
